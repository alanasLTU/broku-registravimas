# Brokų registras (DISTYLE)

Next.js app’as Vercel’iui. Backendas: Supabase (Auth, Postgres + RLS, Storage).

Diegimas ir raktai: [SETUP.md](SETUP.md). SQL schema: [supabase/migrations/20260825120000_init.sql](supabase/migrations/20260825120000_init.sql).

```bash
npm install
# įrašyti .env.local pagal .env.example ir SETUP.md
npm run dev
```

Pirmas prisijungęs el. paštas tampa Distyle (staff). Klientus kviečia **Komanda**. Domenas vėliau: `brokai.distyle.lt`.
